# Analog RSL：模拟集成电路尺寸搜索与经验学习原型

这是一个电阻负载 NMOS 共源放大器的自动尺寸设计实验，零第三方依赖，可离线运行。输入增益、输出极点带宽、负载电容、功耗与饱和余量要求，输出 W、L、RD、VGS，以及三个演示工艺角下的估算结果。

**定位：系统层自学习的最小实验，使用跨任务的交叉熵方法（CEM）更新搜索策略。没有调用大语言模型，没有训练大模型权重，也没有实现自动改写学习算法的强意义递归自我改进。** 改进后的策略参与下一轮候选设计生成，因此构成一个可度量、可保存、可拒绝退化更新的反馈学习闭环。

## 立即运行

需要 Node.js 18 或以上版本，可从 [Node.js 官网](https://nodejs.org/)安装。Windows 下双击 `start.cmd`，会从初始策略开始学习（已有 `data/policy.json` 时会继续学习），随后完成一例尺寸设计。无需 API Key、网络或安装 npm 包。终端结束后按任意键关闭。

也可在本目录打开终端：

```powershell
node analog-rsl.cjs demo
```

独立操作：

```powershell
# 修改 spec.json 后，只做设计，不训练
node analog-rsl.cjs design spec.json

# 从保存的策略继续学习 10 轮
node analog-rsl.cjs train 10

# 在另一组 48 个任务上查看保存策略的表现
node analog-rsl.cjs evaluate

# 运行数值与学习门控检查
node verify.cjs

# 重做初始策略实验；这会覆盖本目录 data 下的已有策略与报告
node analog-rsl.cjs fresh-demo
```

归档的第一次学习结果保存在 `examples/`。首次运行后会自动创建 `data/`，保存你自己的策略与结果；运行时数据已加入 `.gitignore`。直接执行 design 也可以，没有已学习策略时会使用初始策略。

已安装 npm 的环境也可使用 `npm start`、`npm run design`、`npm run train` 和 `npm test`。项目无第三方依赖，不需要先执行 `npm install`。`npm test` 验证模型与归档实验，不修改你保存的策略。

## 修改设计目标

`spec.json` 使用下列字段，数值必须为有限正数：

| 字段 | 意义 | 单位 | 默认值 |
| --- | --- | --- | --- |
| vdd | 电源电压 | V | 1.8 |
| gainDb | 最小低频增益幅值 | dB | 16 |
| bwMHz | 最小输出单极点带宽估算值 | MHz | 4 |
| clPf | 输出负载电容 | pF | 0.8 |
| pmaxMw | 最大直流供电功率 | mW | 0.8 |
| swingV | 最小静态饱和/电源余量，min(VDS−VOV, VDD−VDS) | V | 0.15 |

`swingV` 是工作点余量约束，**不是经过大信号失真验证的输出摆幅指标**。

训练规格范围：VDD 固定 1.8 V，增益 12–20 dB，带宽 1–8 MHz，负载 0.3–1.4 pF，功耗上限 0.35–1.2 mW，余量 0.12–0.20 V。超出此范围可以尝试，但保存策略的效果未经验证。全部目标不一定可同时实现；程序会明确报告未全部达标的情况。

## 它如何学习

1. 初始策略为四维高斯分布，通过有界变换产生 VOV、L、负载压降比例和电流预算比例，再换算为 W、RD 与 VGS。
2. 每轮在 28 个训练任务上，各提出 80 个候选，通过参考电路模型求解工作点、增益、带宽、功耗与余量。
3. 每个任务保留 4 个精英候选。满足全部约束的设计优先，其余按损失排序；由精英样本估计下一代分布的均值与标准差，并保留最低探索宽度。
4. 在 24 个验证任务上，以相同随机种子、相同 32 次评估预算比较旧策略与新策略。只有平均损失降低超过 1%，且达标率不下降，才晋升新策略。
5. 接受后的策略进入下一轮，并保存到 `data/policy.json`。这四维均值和标准差就是跨运行保留的学习状态。
6. 全部轮次结束后，在另外 48 个测试任务上比较初始策略与最终策略。测试结果不参与本次晋升决策。

损失由增益、带宽、功耗、余量及饱和约束违反程度组成，再加较小的功耗与栅面积代理成本。面积项只包含 W×L，未包含电阻、布线等实际版图面积。评估是确定性数值计算，系统不能通过修改评价规则为自己加分。

`training-memory.json` 保存本轮运行的部分精英样本和候选分布，供审计；下一次训练直接复用已学习的策略参数，不会重放该日志。每次运行会覆盖当前报告和经验日志，重要实验应另行备份 `data/`。

## 当前实验结果

已运行 10 轮冷启动实验，接受 2 次更新，最终策略为 v2。

| 48 个测试任务，每个任务 32 次评估 | 初始策略 | 学习后策略 |
| --- | --- | --- |
| 全部约束达标率 | 95.8%（46/48） | 100.0%（48/48） |
| 平均损失，越小越好 | 0.0353 | 0.0132 |

示例设计目标为默认 spec。输出 W≈3.3569 μm、L≈0.31988 μm、RD≈22.377 kΩ、VGS≈0.65519 V。三个演示角分别取最差后：增益约 17.848 dB、带宽约 9.512 MHz、最大功耗约 0.1103 mW、最小余量约 0.209 V。

这些数值来自简化模型的演示，48 个同分布任务不足以支持真实设计场景的泛化结论。验证集被反复用于晋升，存在过拟合可能；如果根据测试集结果调整算法，后续应重新生成未使用过的测试集。后续训练未必持续进步；程序允许停滞并拒绝退化候选。

## 电路模型与边界

NMOS 源极及衬底接地；漏极通过 RD 接 VDD；栅极由理想电压源驱动；输出接 CL。参考模型采用长沟道平方律及沟道长度调制：

- KP = 200 μA/V²，VTH = 0.45 V，λ = 0.035/L，其中 L 的数值以 μm 计。
- 饱和区 ID = 0.5·KP·(W/L)·VOV²·(1+λVDS)。线性区改用 KP·(W/L)·(VOV·VDS−VDS²/2)·(1+λVDS)。
- 二分求解 ID = (VDD−VDS)/RD，再求局部 gm、gds；|Av| = gm·(RD∥ro)。
- BW ≈ 1/[2π·(RD∥ro)·Cout]。Cout = CL + W·0.55 fF/μm + 5 fF，为人为设定的集总寄生电容。
- 演示角：TT；KP×0.85 且 VTH+15 mV；KP×1.15 且 VTH−15 mV。它们是人为扰动，不是任何代工厂的 SS/FF 角。
- W 限制在 0.3–400 μm；L 为 0.18–1 μm；VOV 为 0.08–0.40 V。低过驱动处平方律尤其不准确，保留该范围只为演示搜索。

未包含真实短沟道效应、弱反型、体效应、温度/电源扫描、器件失配、噪声、THD、输入源阻抗和米勒效应的完整频率响应、版图寄生或可靠性规则。**目前不是 SPICE 仿真，也不应据此确定流片尺寸。**

输出的 `.cir` 使用演示 LEVEL=1 模型，可供装有 ngspice 的环境对照运行。它使用同一组 TT 直流参数和集总输出电容；本机实验没有调用 ngspice，因此不能声称 SPICE 验证通过。模型字段含义可参考 [ngspice 官方文档](https://ngspice.sourceforge.io/docs.html)。

## 文件

- `analog-rsl.cjs`：完整模型、搜索、学习、验证门控、命令行和网表导出。
- `spec.json`：可编辑的设计目标。
- `start.cmd`：Windows 一键运行。
- `verify.cjs`：8 项验证，包括工作点解析对照、增益数值导数、负载电容趋势、线性区拒绝、不可行目标、可复现性、晋升门控与首轮策略更新复现。
- `examples/`：已归档的冷启动策略、报告、示例尺寸和演示网表，不含本机路径。
- `data/policy.json`：已学习策略。
- `data/training-report.json`：逐轮候选、晋升决策及学习前后测试结果。
- `data/training-memory.json`：当前运行的训练样本摘要。
- `data/latest-design.json`：完整设计及各演示角的结果。
- `data/latest-design.cir`：可供对照的演示网表。

## 接入真实模拟设计流程

最有价值的下一步是以 ngspice/Spectre 和有权使用的 PDK 替换 `simulate()`，保留训练、晋升和审计结构。由于初始尺寸换算也依赖演示模型，接入 PDK 时还要同步修改 `decode()` 的参数范围和初值规则，重新训练并检查收敛失败、仿真预算以及真实 PVT/失配测试。之后可把任务扩展到五管 OTA、两级 Miller 运放，加入 GBW、相位裕度、压摆率和噪声约束。
